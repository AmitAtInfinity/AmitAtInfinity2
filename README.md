# 🌊 The Voyage

**Interactive 3D portfolio exploring my work through an ocean world, with a ship to sail.**

## ✨ About

The Voyage is an interactive 3D portfolio designed as an ocean adventure. Instead of a traditional scrolling portfolio, visitors can sail across the ocean and explore different islands to discover my work, skills, experience, and journey.

## 🚢 Features

- 🌊 Interactive 3D ocean
- 🚢 Sailable ship
- 🏝️ Interactive islands
- 🎮 Smooth navigation and controls
- 🎨 Immersive visual experience
- ⚡ Optimized 3D performance

## 🛠️ Built With

- React
- Vite
- Three.js
- React Three Fiber
- JavaScript
- HTML & CSS
